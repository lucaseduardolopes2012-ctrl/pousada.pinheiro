# Site da Pousada dos Pinheiros

Site próprio (HTML, CSS e JS puros). Para hospedar na Vercel, envie esta pasta inteira como um projeto novo
(sem build: framework "Other", sem comando de build, pasta de saída `.`).

- `index.html`: a página.
- `estilo.css`: o visual (cores no topo, em `:root`).
- `site.js`: o funcionamento. A configuração fica no topo (`CONFIG`).
- `img/`: as fotos.
- `vercel.json`: cabeçalhos de segurança.

Os quartos, preços, horários e pedidos vêm do sistema de reservas (o mesmo banco e o mesmo painel das outras pousadas),
pelo endereço `pousada-dos-pinheiros`. Enquanto a pousada não estiver cadastrada e aprovada no sistema, o site funciona
pelo WhatsApp: a busca de datas e os quartos viram mensagem pronta para a pousada.
